
# Employee Live Location Tracker

A responsive Flutter Web dashboard for monitoring employee live location in real time. The application displays employee details, live map location, location history, statistics, and automatic location updates through an API.

### Features

* 📍 Real-time employee location tracking
* 🗺️ Interactive live location map
* 👤 Employee information card
* 📊 Dashboard statistics
* 🕒 Location history tracking
* 🔄 Automatic location updates every few seconds
* 🌙 Light and dark mode
* 📱 Responsive web design
* ⚡ Refresh and retry functionality

### Technologies

* Flutter
* Dart
* Flutter Web
* REST API
* Responsive UI

### Project Status

Demo web application completed. Currently improving the UI design, responsiveness, and overall user experience.
